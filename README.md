# JLPT 단어 셔플

JLPT N5~N1 단어를 자동으로 넘기는 오프라인 플래시카드. 한국인 학습자용 — 한자를 못 읽어도 되게 **かな 읽기 + 한글 발음 + 한국 한자음**을 항상 같이 보여준다.

세 가지를 연습한다. 열면 뭘 할지 고르는 화면이 먼저 나온다.

| | 수록 | 방식 |
|---|---|---|
| **단어** | JLPT 어휘 9,543개 | 자동으로 넘어가는 플래시카드 |
| **한자** | 2,142자 | 자동으로 넘어가는 플래시카드 |
| **かな** | 히라가나·가타카나 244자 | 타자 드릴. 글자를 보고 로마자를 치면 맞는 순간 넘어간다. 바퀴마다 최고 기록·연속 만점이 쌓인다 |
| **읽기** | 실제 뉴스 기사 46편 | 한자 위에 후리가나. 문장마다 번역과 발음(사람 목소리에 가까운 음원) |

## 실행

```
open index.html          # 그냥 더블클릭해도 됨
./start.command          # 폰트까지 100% 확실하게 (로컬 http 서버)
```

`F` 전체화면 → 보조 모니터에 띄워두고 방치하는 용도. 조작은 `?` 로 확인.

웹에서도 같은 앱이 돈다: <https://alfex4936.github.io/JLPT/>

## 기사 링크 공유

읽기 모드에서 기사를 넘기면 주소창이 따라온다. 그 URL 을 그대로 보내면 상대는 그 기사로 바로 들어온다.

```
https://alfex4936.github.io/JLPT/#read=r17525
```

`r17525` 는 ウィキニュース 문서 번호다. 기사를 더 넣어 덱 순서가 바뀌어도 링크는 같은 기사를 가리킨다.
`file://` 로 열어 둔 창에서도 똑같이 동작한다.

## 카드에 뭐가 있나

```
まいあさ          ← かな (읽을 수 있는 단서)
毎朝              ← 표기
마이아사 · 한자음 매조   ← 한글 발음 + 한국 한자음
매일 아침 / 명사
毎朝コーヒーを飲みます。
まいあさコーヒーをのみます。   ← 예문 かな 읽기
마이아사 코히오 노미마스        ← 예문 한글 발음 (어절 단위로 끊음)
매일 아침 커피를 마십니다.
```

예문 한글 발음은 `tools/example-hangul.js` 가 한자 표기와 かな 읽기를 정렬해 어절을 잘라낸 뒤 옮긴다. 한 덩어리로 붙이면(`고카조쿠니요로시쿠오쓰타에쿠다사이`) 못 읽으므로 끊는 게 핵심. 설정에서 끌 수 있다.

**한자음**이 핵심 후크다. `問題=문제`, `雑談=잡담`, `楕円=타원` 처럼 한국어와 겹치는 한자어가 JLPT 어휘의 큰 덩어리다.
전체 9,543 단어 중 **4,317개(45%)는 한자음이 한국어 뜻과 그대로 일치** → 이 카드에는 `한자음 = 한국어` 배지가 붙는다. 배지가 보이면 외울 게 아니라 이미 아는 단어다.

2010년 개편 후 공식 어휘 목록이 없어서, 공개된 JLPT 목록은 서로 다른 사람들의 선별 결과다. 그래서 여러 목록을 교차 대조해 두 번 채웠다:

- **+302** — tanos.co.uk 계열 목록과 [stephenmk/yomitan-jlpt-vocab](https://github.com/stephenmk/yomitan-jlpt-vocab)(JMdict 로 표기 정규화한 판)의 합집합에서 빠진 것(`tools/gap-words.json`). 원천 데이터가 `足; 脚` 이형태·`～回` 접사·`(かん)` 주석 행을 처리하다 흘린 것들로, 顔·父·母 같은 N5 핵심어가 여기 있었다.
- **+912** — 다른 계열 JLPT 단어 덱과 대조해 나온 것(`tools/rk-words.json`, 추출은 `tools/fetch-realkana.js`). tanos 계열엔 없는 현대 실무·IT 어휘가 많다 — 検索 更新 添付 返信 送信 画面 入力 残業 本社 会社員 携帯電話 領収書 振り込む 交通費 自動販売機. 이형태는 JMdict 엔트리 동일성으로 걸러냈다(旨い↔うまい 는 같은 단어, 韓国↔勧告 은 다른 단어).

> **합격 보장 아님.** JLPT는 2010년 개편 때 공식 어휘 목록(出題基準) 발행을 중단했다. 위 목표치는 널리 인용되는 추정값이고, 원천 어휘 목록도 커뮤니티(Anki 덱) 기반이라 급수 배정이 공식 기준과 다를 수 있다.
> 게다가 시험은 文字·語彙 / 文法·読解 / 聴解 세 축인데 이 앱은 **어휘만** 다룬다. 문법 항목(〜ばかり, 〜わけではない …)은 0개다. 어휘 토대로는 충분히 쓸 만하고, 합격에는 문법·독해·청해를 따로 해야 한다.

모든 단어에 한국어 뜻(최대 3개)·품사·일본어 예문·예문 かな 읽기·예문 번역이 붙어 있다. 검증 결과: 예문-단어 정합률 100%, かな 읽기에 한자 0건, 예문 결손 0건, 중복 0건.

## 한자 카드 (설정 → 학습 대상 → 한자)

단어 덱에 실제로 등장하는 한자 **2,142자**를 한 글자씩 넘긴다. 기본값은 단어이고, 이건 옵션이다.

카드 한 장에 들어가는 것 — 한자, **훈음**(`매양 매`), 한국 한자음 배지, 음독·훈독을 かな + 한글로, 한국어 뜻, 그리고 **그 한자를 쓰는 우리 덱 단어 3개**(표기 + かな + 한글 + 뜻).

```
N5  6획
                每
     매양 매   한자음 매
     음 マイ 마이   훈 ごと 고토   ごとに 고토니
     1 매번   2 ~마다
     毎月 まいげつ 마이게쓰            매달
     毎週 まいしゅう 마이슈            매주
     毎年 まいねん 마이넨              매년
```

예시 단어는 새로 만든 게 아니라 **단어 덱에서 가져온다** — 이미 카드로 본 단어라 한자와 단어가 서로 보강되고, 낮은 급수·한자음 배지가 붙은 단어를 먼저 고른다. 단어 줄을 클릭하면 그 단어를 읽어 준다(한자 한 글자는 음성이 읽기를 고를 수 없다 — `日`이 ニチ인지 ひ인지 모른다. 그래서 발음 버튼도 대표 단어를 읽는다).

훈음 2,139자, 한국 한자음 2,140자. 빠진 건 `雫`·`枠` 처럼 일본에서 만든 국자(国字)로 한국 한자음이 존재하지 않는다.

즐겨찾기·채점·본 횟수는 단어와 **따로** 쌓인다. 급수 필터는 같이 쓰고, 한자음 필터는 단어에만 적용된다.

## かな 연습

히라가나·가타카나 **244자**를 받아쓰기로 연습한다. 글자 하나가 크게 뜨고, 로마자를 치면 **맞는 순간 바로 다음 글자로 넘어간다**(Enter 를 누를 필요 없다). 맞히거나 정답을 본 뒤에 그 글자를 읽어 준다.

```
      ひらがな  기본          정답 12 · 오답 3

                 き

         [ ki    ]
          ki  키
```

- **틀리면** 카드가 흔들리고 입력이 지워진다. 3번 틀리면(1~6 설정) 정답을 보여주고, 그걸 그대로 쳐야 넘어간다.
- **틀린 글자는 그 바퀴가 끝나기 전에 다시 나온다.** 카운터(`12 / 71`)는 떼어낸 글자 수다 — 틀린 글자는 다시 나와서 바로 맞힐 때까지 세지 않는다.
- **한 바퀴가 끝나면 틀린 글자를 모아 보여준다.** 글자마다 로마자·한글·틀린 횟수가 붙고, `틀린 N자만 다시`(<kbd>Enter</kbd>)로 그 글자들만 한 바퀴 더 돌릴 수 있다. 다 맞힌 바퀴는 멈추지 않고 바로 다음 바퀴로 넘어간다 — 보여줄 게 없으면 멈출 이유도 없다.
- **훈령식·일본식 입력도 받는다.** `shi`/`si`, `chi`/`ti`, `tsu`/`tu`, `fu`/`hu`, `sha`/`sya`, `ja`/`jya`/`zya`, `wo`/`o`, `n`/`nn`.
- 글자별 정답·오답 수가 쌓이고 카드 위에 보인다.

### 연습할 글자 고르기

`글자 고르기` 를 누르면 오십음도가 나온다. **선택 단위는 열(列)** 이다 — か행을 누르면 かきくけこ 5자가 한꺼번에 켜진다. 그룹별 `전체` 버튼도 있다. 기본값은 히라가나 기본 71자.

| 표 | 자수 | 내용 |
|---|---|---|
| 히라가나 기본 | 71 | あ~ん + 濁音·半濁音 (が ざ だ ば ぱ) |
| 히라가나 요음 | 36 | きゃ しゃ ちゃ … ぴょ |
| 가타카나 기본 | 71 | ア~ン + 濁音·半濁音 |
| 가타카나 요음 | 36 | キャ シャ チャ … ピョ |
| 가타카나 확장 | 30 | ヴァ ティ トゥ ツァ ファ シェ ジェ … 외래어 전용 |

## 읽기 (실제 뉴스)

[ウィキニュース](https://ja.wikinews.org) 기사 **10편 · 68문장**. 가공한 학습용 문장이 아니라 실제로 쓰인 일본어다.

- **한 문장씩 크게.** 기사 전체를 한 화면에 욱여넣으면 문장이 작아지고 후리가나는 그 절반이라 濁点이 안 보인다. 한 문장만 띄우니 본문 54px·후리가나 34px(모바일도 35/21px)까지 커진다. 다음 문장은 아래에 흐리게 미리 보이고, 눌러서 바로 건너뛸 수 있다. `O` 로 기사 전체 보기와 오갈 수 있다.
- **`←` `→` 로 문장을 넘긴다.** 끝에 닿으면 다음 기사로 넘어간다. 자동 넘김은 없다.
- **한자 위에 후리가나.** かな 만 읽을 수 있으면 기사 전체를 소리 내어 읽을 수 있다. `R` 로 껐다 켤 수 있고, 끄더라도 줄 높이는 그대로라 읽던 자리를 잃지 않는다.
- **문장을 누르면 그 문장을 읽어 준다.** 한자 표기가 아니라 かな 읽기를 음성에 넘긴다 — 단어 카드와 같은 이유로, 한자를 넘기면 음성이 읽기를 틀린다.
- **눈 버튼은 그 문장의 번역만 연다.** `K` 로 전부 열고 닫을 수 있다. 기본은 닫힌 상태다.
- **후리가나 글꼴·크기를 고를 수 있다.** 濁点(゛)과 半濁点(゜)은 작으면 구별이 안 된다 — ば 와 ぱ 를 못 가리면 후리가나가 제 일을 못 한다. 루비는 전부 かな 라서 かな 전용 글꼴을 그대로 쓸 수 있어서, 13px 에서 여덟 가지를 나란히 놓고 재 본 뒤 획이 굵고 半濁点 동그라미가 또렷한 **Kosugi Maru** 를 기본으로 삼았다(Noto Sans JP 가 제일 가늘어 뭉갰다). 더 굵게 원하면 매직펜·굵게, 크기는 네 단계.
- 자동 넘김이 없다. 읽는 속도는 사람마다 다르고, 남은 시간 바가 있으면 쫓기게 된다.
- 문장이 길어 화면을 넘치면 글자를 줄이지 않고 스크롤한다 — 글자 크기가 이 모드의 존재 이유다.
- 넓은 화면에서는 화면 폭을 쓴다(최대 1500px, 일본어 한 줄 24자). 좁은 화면에서는 폭에 맞춰 줄어든다.

기사는 덱과 겹치는 정도로 골랐다 — 실린 10편은 **본문 한자의 97~100%가 이미 한자 카드에 있는 글자**다.

### 후리가나는 어떻게 붙었나

기사에 후리가나는 원래 없다. 형태소 분석기(kuromoji)가 읽기를 주긴 하지만 **뉴스에서 틀리는 곳이 하필 날짜·고유명사·숫자**다(`8月`→つき, `原木中山`→げんぼくちゅうざん, `〜の間`→ま). 게다가 아라비아 숫자에는 읽기를 아예 안 준다.

그래서 읽기를 세 겹으로 거른다:

1. 숫자와 조수사는 **함께** 읽는다 — `10日`은 とおか(じゅう+とおか 가 아니다), `9時`는 くじ, `1本`은 いっぽん.
2. 분석기의 읽기는 **정답이 아니라 힌트**로만 쓴다. 정답 かな 는 문장 전체 읽기에서 잘라 오고, 힌트와 맞는 배치에 가점을 줄 뿐이다. 분석기가 틀리면 힌트가 안 맞을 뿐 틀린 루비가 되지는 않는다.
3. 표기와 읽기가 **안 맞으면 그 문장을 버린다.** 정렬 실패가 곧 검수 대상이다.

이 정렬기는 기존 예문 9,543개로 검증했다 — 99.99% 정렬, 재조립 불일치 0건. (통과 못 한 1건은 예문 데이터 자체의 오타였다.)

> 정렬에 성공했다는 건 읽기가 표기와 **앞뒤가 맞는다**는 뜻이지 읽기가 옳다는 보장은 아니다. 고유명사 읽기는 여전히 틀릴 수 있고, 한자를 못 읽으면 스스로 잡아낼 수 없다. 기사를 늘릴 때는 `tools/cache/review/reading-draft.tsv` 를 반드시 검수할 것.

## 일본어 글꼴 (설정 → 일본어 글꼴)

같은 글자를 다른 글꼴로도 읽어내야 실제로 읽는 것이다. 12종을 고를 수 있고 `あ` 미리보기가 함께 뜬다.

교과서체(Klee One) · 고딕(Noto Sans JP) · 둥근고딕(Kosugi Maru) · 명조(Shippori Mincho) · 손글씨(Zen Kurenaido) · 매직펜(Yusei Magic) · 둥근 팝(Hachi Maru Pop) · 굵은 제목(Dela Gothic One) · 시스템 글꼴(설치된 것만 표시) · **무작위**.

번들 글꼴 6종은 **かな 만** 담아 서브셋했다(각 18~36KB). 그래서 단어·한자 카드에서 골라도 かな 만 그 글꼴로 바뀌고 한자는 교과서체가 그린다. `무작위` 는 かな 카드마다 글꼴을 바꾼다 — 단어·한자 카드는 기본 글꼴 그대로다.

## 한자음 필터 (설정 → 한자음 필터)

| 필터 | 단어 | 성격 |
|---|---|---|
| 전체 (기본) | 9,543 | — |
| **한자음 = 한국어** | 4,317 | 問題=문제. 외울 게 없다. 빨리 훑는 구간 |
| **한자음 다름** | 4,066 | 勉強=면강/공부, 台所=태소/부엌. 한자음이 오히려 방해되는 진짜 암기 구간 |
| **かな 단어** | 1,160 | あげる 같은 和語. 한국어 도움 0 |

`배지 단어는 절반 시간만` 을 켜면 전체 재생 중에도 한자음=한국어 단어만 전환 간격이 절반으로 줄어든다.

음독 한자어(한자 2자 이상 명사)는 76%가 배지, 訓読 단어(한자+히라가나)는 20%뿐이다. 급수보다 이 축으로 시간을 나누는 게 효율이 높다.

채점은 어느 모드에서나 `1`·`2`·`3` 으로 기록된다. 간격은 Leitner 상자 — 몰라요 10분, 그다음 1일 → 3일 → 7일 → 21일 → 60일. 알아요면 한 칸 위, 애매면 한 칸 아래, 몰라요면 처음으로.

전체 재생은 9,543단어를 15초씩 돌면 한 바퀴가 **39.8시간**이라, 같은 단어를 다시 보기까지 이틀 넘게 걸린다(에빙하우스 곡선 기준으로는 이미 다 잊은 뒤). 배경으로 켜두는 용도로는 그대로 쓰고, 실제로 외우려면 배치 루프 + 채점을 쓰는 게 맞다.

설정: 전환 간격(3~60초, 기본 15초), 급수 필터, 가리기 모드와 공개 지연, TTS 켜기/끄기·음성 선택·**음량**·속도·예문 읽기·두 번 읽기, 글자 크기, 테마.

발음은 클릭으로도 듣는다 — **큰 단어를 누르면 단어**(<kbd>V</kbd> 와 같음), **예문 줄을 누르면 예문**. 예문은 かな(`ek`)를 읽는다. 한자 표기를 넘기면 음성이 읽기를 틀릴 수 있어서다(`今日` 을 こんじつ 로 읽는 식). 음소거 중에는 클릭해도 소리가 나지 않는다.

## 데이터

- 원천 어휘: [jlpt-vocab-api](https://github.com/wkei/jlpt-vocab-api) (표기·かな·급수·영어 뜻)
- 한국 한자음: [KANJIDIC2](http://www.edrdg.org/kanjidic/kanjidic2.xml.gz) `korean_h` 필드
- 한글 발음 표기: `tools/kana2hangul.js` — 국립국어원 일본어 표기법 기반 (어두 평음/어중 격음, 장모음 미표기)
- 한국어 뜻·품사·예문: 생성 파이프라인(`tools/`) 산출물
- かな 표·로마자: `tools/build-kana.js` 의 상수. 배치는 오십음도 그대로, 한글 표기는 위와 같은 변환기
- 읽기 기사: [ウィキニュース 日本語](https://ja.wikinews.org) (CC BY 4.0). 후리가나는 `tools/furigana.js`, 번역은 이 저장소에서 생성

### 재생성

```
SCRATCH=<작업디렉터리> node tools/build-base.js   # base.json + 번역용 청크 TSV
# 청크별 번역 결과를 $SCRATCH/build/out/*.jsonl 로 채운 뒤
SCRATCH=<작업디렉터리> node tools/merge.js        # data/words-n*.js 생성 + 품질 리포트
node tools/build-manifest.js                     # 시작 화면 개수표 (덱을 다시 만들면 항상)
```

데이터 스키마와 UI 요구사항은 [SPEC.md](SPEC.md).
